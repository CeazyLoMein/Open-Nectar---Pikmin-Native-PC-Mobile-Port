# P1 experimental complete actor frames

Prototype visual captain/Pikmin DATA only. Not an exact-scene save or complete world. No live sockets/session/UI/guest engine application. Default runtime inactive, gated by existing NECTAR_COOP_WORLD build option. Test data traverses actual P1 capture through packActorFrame to ActorFrameReceiver.

NCF1 fragment header48bytes, big endian: magic u32, version u8=1, flags u8=keyframe, accepted scene epoch u16, session u64, frame sequence u64, authoritative tick u64, complete encoded body length u32, FNV1a64 body integrity u64, fragment index u16, count u16. Payload after header is one balanced contiguous slice of the complete encodeWorldDelta keyframe. Each fragment includes the same immutable metadata. Packet budget defaults to caller choice, at most1200bytes; outer transport overhead is additional. Default receiver bounds128KiB,512records,512parts,2s fixed timeout; hard config bounds1MiB/4096records/2048parts. Wrong version/flags/geometry/length rejected before assembly allocation. No silently omitted records.

Invoke receiver only for authenticated HOST bytes after existing session/build/content/scene compatibility succeeds. This component does not authenticate, encrypt, acknowledge or retransmit. FNV is accidental-integrity detection, not security. Caller owns accepted session/epoch and must never accept it from the packet or reuse a session nonce. New begin discards the previous context; caller enforces monotonic accepted epochs. Single owning thread; queue transport events, then publish/apply on a safe simulation boundary. Never independently simulate/save guest progress.

Newest in-flight frame supersedes older incomplete frames; late completed/expired frames cannot replay. Packet duplicates don't advance completion or extend timeout. Mismatching metadata/conflicting duplicates don't poison good pending bytes. No partial state becomes visible, including despawns. Only after full assembly/checksum and world/actor decoding does current() change. Requires one host captain, at most one captain per player, correct kind/schema/epoch, unique IDs, finite/ranged state and included captain for assigned owner/leader. No Pikmin is valid too. Unknown future actor schemas are rejected until explicitly supported. Latest complete frame remains on loss/timeout/invalid content. end()/new accepted scene clears old replicas. Applying changes to actual guest actors is future work.

Host pc_coop_world_capture_packets validates strictly increasing frame IDs, nondecreasing ticks and explicit active session; captures actual current P1 actors once and returns self-owned byte vectors. Failed call leaves output unchanged: never transmit output on false. Packet memory allocated via game-global allocators may belong to scene heap; future network queue must use durable ownership or drain before stage reset. Vectors alone do not establish cross-scene lifetime safety.

Tests: loss/reorder/duplicates, complete replacement/despawn,1000 varying squads, malformed/truncated/oversized fragments, corruption, stale session/scene/frame/tick, fixed expiry, valid-checksum but invalid semantic records, NaN/schema/ownership validation; actual engine/pool capture to receiver, with default-off compilation retained. Real-network two-phone rendering/gameplay remains untested.
